# Bulk URL Google Indexing Tool (bklink / MX Verify)

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://python.org)
[![Deploy on Render](https://img.shields.io/badge/Deploy-Render-success)](https://render.com)

Find out what the links you paid for are really worth. Upload the placement list a vendor or PR distributor sold you. This tool resolves every publication to its server, checks each link live, and estimates what the list is actually worth — so you can see which placements are real, which share hosting, and which are already dead.

## 🚀 Core Features

* **Complete Infrastructure Resolution:** Resolve every host, IP, ASN, and follow state. Go beyond a vendor's link count to see where each publication actually lives and how much of the list quietly shares infrastructure.
* **Vendor Accountability:** Every audited link is grouped by the provider or PR distribution agency that sold it. Instantly see how many of their placements turned out to be co-hosted spam.
* **Link Rot Monitoring:** Catch link rot before your client does. Re-check every URL whenever you want; the dollar value recalculates around what is still live without paying for new vendor lookups.
* **Multi-API Indexing Automation:** Streamline URL submission and indexing warm-up workflows across multiple search APIs including Exa, Tavily, Jina AI, and Brave Search.

## 🛠️ Tech Stack

* **Backend:** Python (`main.py`)
* **Frontend:** HTML templates (`/templates`)
* **Deployment:** Pre-configured for Render (`render.yaml`)
